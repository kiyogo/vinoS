# Quy tac lam viec cua agent

1. Sau moi lan thay doi code, phai doc va kiem tra lai toan bo phan code vua sua.
2. Phai xem lai `git diff` va chay cac lenh build/test phu hop truoc khi ket luan cong viec da hoan thanh.
3. Neu build hoac test that bai, phai sua loi va kiem tra lai; neu khong the sua, phai bao ro loi con ton tai.
4. Sau khi code da duoc kiem tra, phai commit va push len duy nhat repository sau:
   `https://github.com/ngdaison/KOS2.git`
5. Khong duoc push code sang bat ky repository hoac remote nao khac, ke ca `vinos`.
6. Khong dua cac thay doi khong lien quan cua nguoi dung vao commit.
